# Software Design Patterns & Architecture 📐🏗️

Welcome to the **Software Design and Architecture** repository completed at **Holberton School**. This repository covers software design patterns, architectural principles, and Object-Oriented modeling utilizing **Python** and **UML** (Unified Modeling Language) diagrams.

---

## 📌 Modules & Core Concepts

| Directory / Module | Description & Concepts Covered | Technologies / Notations |
| :--- | :--- | :--- |
| `design_patterns` | Implementation of classic software design patterns (Creational, Structural, Behavioral) | Python, Decorators, OOP Principles |
| `uml_intro` | Visual software modeling, class diagrams, and sequence diagrams | Mermaid.js, UML Specifications |

---

## 🛠️ Environment & Tools

- **Languages / Notations:** Python 3.8+, Mermaid (UML)
- **Methodologies:** Object-Oriented Design (OOD), Design Patterns
- **Environment:** Linux / WSL2
